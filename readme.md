## Projects

**[HellenicClinic](https://github.com/iorii1/HellenicClinic)**
JavaFX desktop application for clinic management — patient/doctor records and appointment scheduling with double-booking prevention. CSV-based persistence.

**[Hellenic-University](https://github.com/iorii1/Hellenic-University)**
Full-stack web application (PHP/MySQL) for university record management, with role-based access for students and professors.
